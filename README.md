# Clínica Dental Sonríe Los Ángeles

Sitio web de la Clínica Dental Sonríe Los Ángeles (Los Ángeles, Chile): información de servicios (evaluación, odontología general, limpiezas, estética dental, urgencias, rehabilitación oral, prótesis y ortodoncia) y página para reservar hora.

## Estructura

| Archivo | Descripción |
|---|---|
| `index.html` | Página principal |
| `agenda.html` | Reserva de horas |
| `styles.css` | Estilos |
| `script.js` | Lógica del sitio |
| `robots.txt`, `sitemap.xml` | SEO |

## Desarrollo

Es un sitio estático, sin build. Para verlo localmente basta con abrir `index.html` o servir la carpeta:

```bash
python3 -m http.server 8000
```

## Despliegue

Publicado en Netlify:

```bash
netlify deploy --prod
```
